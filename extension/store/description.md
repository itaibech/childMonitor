# Child Monitor - store listing

**Visibility:** Unlisted (Chrome Web Store) / Hidden (Edge Add-ons)

## Single purpose

Parental monitoring on family-owned devices.

## Short description (max 132 characters)

Reports the active tab's address and title to the Child Monitor service on this PC. Family use only.

## Detailed description

Child Monitor is part of a private family parental-monitoring system. It is installed only on computers owned by the family, by the parent, as a managed (force-installed) extension.

What it does: it records the address (URL), page title and time of the active browser tab, and sends them only to the Child Monitor service installed on the same Windows PC (through Chrome/Edge native messaging). The service forwards the data to the family's own private backend, readable only by the parent's Google account.

What it does not do: it sends no data to third parties, does not sell or share data, does not read page content, form fields or passwords, and has no ads or analytics.

This extension is not intended for general use. It does nothing without the Child Monitor service installed on the PC.
